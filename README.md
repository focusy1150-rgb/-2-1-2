เป็นระบบที่ให้กันภายในห้อง ม2/1 เท่านั้น ไม่ได้ทำไปเผยแผ่สู่สาธารณะ
และตอนนี้ยังไม่มีระบบที่นำไปใช้เองโดยคนอื่น

Script ไนเว็ปที่มีส่วนที่ให้aiทำในส่วนหนึ่ง เนื่องจากบ้างระบบทำไม่ได้ก็ต้องเข้าใจกันด้วยนะครับ🙏
และมีระบบเชื่อมไปยังFirebase เพิ่อทำหน้าที่ 1.เก็บข้อมูลถาวร: การจอง คำขอย้าย/สลับที่ เวลาเปิดจอง และปิดเว็บหรือปิดเครื่องแล้วข้อมูลไม่หาย
                                   2.ส่งข้อมูลใหม่ให้ทุกเครื่องทันที: เมื่อมีคนจองโต๊ะ ทุกเครื่องที่เปิดเว็บอยู่จะเห็นโต๊ะนั้นเปลี่ยนเป็นสีแดงภายในเสี้ยววินาที โดยไม่ต้องรีเฟรช
                                   3.กันคนจองโต๊ะซ้ำ: ถ้าสองคนกดโต๊ะเดียวกันพร้อมกัน Firebase ตัดสินว่าใครมาก่อน คนที่มาทีหลังจะถูกแจ้งว่าโต๊ะถูกจองไปแล้ว
                                   4.บอกเวลาที่ถูกต้อง: ระบบนับถอยหลังเปิดจองใช้เวลาของเซิร์ฟเวอร์ ไม่เพี้ยนตามนาฬิกาของแต่ละเครื่อง
